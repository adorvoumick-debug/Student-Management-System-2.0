STUDENT MANAGEMENT SYSTEM
Java Swing + MySQL + JDBC + NetBeans

FEATURES
- Add student
- View all students
- Update selected student
- Delete selected student
- Search by name, department, or email
- Input validation
- Beginner-friendly Swing interface
- MySQL database using JDBC

REQUIREMENTS
1. JDK 17 or later
2. MySQL Server / XAMPP MySQL
3. Maven internet access for the first build

DATABASE SETUP
1. Start MySQL.
2. Open MySQL Workbench or phpMyAdmin.
3. Run the file: student_management.sql
4. Open:
   src/main/java/com/studentmanagement/DatabaseConnection.java
5. Change USERNAME and PASSWORD to your MySQL login.

OPEN IN VS CODE
1. Extract this ZIP.
2. Open VS code.
3. Select File > Open Project.
4. Select the StudentManagementSystem folder.
5. Wait for Maven dependencies to download.
6. Run Main.java, or right-click the project and choose Run.

IMPORTANT
- Default database name: student_management
- Default username in code: root
- Default password in code: blank
- Change these values if your MySQL uses a password.
